# テスト計画

## 自動テストの種類
| 種類 | ツール | 実行タイミング |
| --- | --- | --- |
| lint（書き方チェック） | oxlint | PR ごと（CI） |
| 型チェック | TypeScript | PR ごと（CI） |
| 単体・画面テスト | Vitest + Testing Library | PR ごと（CI） |
| ビルド | Vite | PR ごと（CI） |
| E2E（実ブラウザ操作） | Playwright（390px・320px） | PR ごと（CI） |

## Phase 0 のテスト
- 起動画面にアプリ名が見出しとして表示される
- Phase と「開発中」「データ未登録」が明示される
- 評価欄が 0 ではなく「— / 未評価」になる

## Phase 1 のテスト
- 単体（19件）：未評価・保留は数字を出さない／暫定ラベル／型で「未評価なのに点数あり」を禁止／架空データ全件に isSample と（架空）／日本時間表示／全タブ遷移／一覧→詳細／不正ID・不正URL／星→お気に入り
- E2E（2幅×4件）：横はみ出しなし・コンソールエラーなし／ナビ44px以上／一覧→詳細→戻る／直接開いて再読込・戻る

## Phase 2 のテスト
- 単体（57件）：並び替え（未評価は常に末尾・各昇降順）／範囲・距離・キーワード（全角半角・かなカナ）／位置不明の店は距離で消さない／低信頼は評価だけ隠し店舗数は不変／URL ⇄ 条件の往復・不正値／IndexedDB 保存（設定・お気に入り・履歴10件・プリセット）／再起動後の復元／GPS 拒否・許可（候補提示のみ）／経路リンク（確認済みのみ）／距離計算
- E2E（2幅×10件）：上記に加え、再読み込み後の地域・お気に入り保持、共有 URL、GPS 拒否/許可、一覧⇄地図、0件時のリセット、設定・地図画面も横はみ出しなし
