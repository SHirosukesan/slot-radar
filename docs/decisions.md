# 決定事項（Decision Log）

| D-001 | 2026-10-18 | 技術構成は React + TypeScript + Vite | 仕様 2章の推奨。型で壊れにくく、開発が速い |

| D-005 | 2026-10-18 | 公開は GitHub Pages（Actions 方式）を第一候補。`base: './'` で相対パスビルド | 仕様 1章。無料。サブパス配信でも動く |

| D-009 | 2026-10-18 | リポジトリは **Public** で運用する（利用者承認） | GitHub Pages を無料で使うため。秘密情報・個人データは一切コミットしない |
| D-010 | 2026-10-18 | GitHub Pages で公開（Actions 方式）。URL: https://shirosukesan.github.io/slot-radar/ | 利用者承認。スマホから URL で確認できる |

| D-015 | 2026-10-18 | E2E は Playwright、390px と 320px の2幅で実行 | 小さいスマホでも崩れないことを CI で保証 |
