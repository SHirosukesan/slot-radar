## 記入ルール
- 利用規約・robots.txt・API 条件を確認した日付と URL を残す。
- 無断の高頻度スクレイピング、ログイン回避、X / LINE への自動アクセスは行わない。
- 取得失敗と「新着なし」を区別して記録する。
- 頻度は「設計目標」であり、規約・費用で実際は変わる。
