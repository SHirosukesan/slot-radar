# 変更履歴

## [0.2.0] - 2026-10-18 — Phase 2
### 追加
- 端末内保存（IndexedDB）：設定・お気に入り・検索履歴・検索プリセット
- 初回の地域設定（47都道府県）と設定画面
- 並び替え（おすすめ/総合/設定狙い/ハイエナ/更新/距離）と昇順・降順。穴場候補は Phase 5 まで選択不可
- 絞り込み（キーワード・範囲・距離・お気に入りのみ・低信頼の評価を隠す）、検索条件の URL 共有、0件時の案内
- 一覧⇄地図切替（Leaflet + OpenStreetMap）
- Googleマップ経路リンク（位置確認済みの店のみ）
- GPS で近くの店舗候補（拒否時の案内つき）、一時検索地点
- 架空店舗を8件に増加（大阪・位置不明・閉店などの確認用）
### 修正
- 同じミリ秒に保存した履歴・プリセットの順番が入れ替わる問題
